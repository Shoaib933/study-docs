CI/CD Security (Workload Identity Federation)
We must allow GitHub Actions to securely deploy to GKE without downloading or storing static JSON
keys. We use OIDC Trust.
1. Set Environment Variables(cmd)

set PROJECT_ID=kubernetes-project-506705
set GITHUB_REPO=shoaibdev26/distributed-lovable
set SERVICE_ACCOUNT=github-actions-gke@%PROJECT_ID%.iam.gserviceaccount.com

//To see account
E:\STUDY\distibuted lovable\distributed-lovable\k8s\proxy>echo %SERVICE_ACCOUNT%
github-actions-gke@kubernetes-project-506705.iam.gserviceaccount.com
--------------------------------------------------------------------------------------------------------------------------------------------------------
2. Create the Service Account & Grant K8s Access
(cmd)
gcloud iam service-accounts create github-actions-gke --project="%PROJECT_ID%" --display-name="GitHub Actions GKE Deployer"
gcloud projects add-iam-policy-binding "%PROJECT_ID%" --member="serviceAccount:%SERVICE_ACCOUNT%" --role="roles/container.developer"
--------------------------------------------------------------------------------------------------------------------------------------------------------
3. Create the Identity Pool and Provider (The Trust Bridge)
CMD
gcloud services enable iamcredentials.googleapis.com --project="%PROJECT_ID%"
gcloud iam workload-identity-pools create "github-pool" --project="%PROJECT_ID%" --location="global" --display-name="GitHub Actions Pool"
gcloud iam workload-identity-pools providers create-oidc "github-provider" --project="%PROJECT_ID%" --location="global" --workload-identity-pool="github-pool" --display-name="GitHub Provider" --attribute-mapping="google.subject=assertion.sub,attribute.actor=assertion.actor,attribute.repository=assertion.repository" --attribute-condition="assertion.repository == '%GITHUB_REPO%'" --issuer-uri="https://token.actions.githubusercontent.com"

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
4. Bind the Service Account to the GitHub Repo
CMD
>>FOR /F "tokens=*" %i IN ('gcloud projects describe %PROJECT_ID% --format="value(projectNumber)"') DO set PROJECT_NUMBER=%i
>>echo %PROJECT_NUMBER%

gcloud iam service-accounts add-iam-policy-binding "%SERVICE_ACCOUNT%" --project="%PROJECT_ID%" --role="roles/iam.workloadIdentityUser" --member="principalSet://iam.googleapis.com/projects/%PROJECT_NUMBER%/locations/global/workloadIdentityPools/github-pool/attribute.repository/%GITHUB_REPO%"

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------
5. Generate the Provider String
CMD
45:00
>>echo projects/%PROJECT_NUMBER%/locations/global/workloadIdentityPools/github-pool/providers/github-provider
>>echo projects/%PROJECT_NUMBER%/locations/global/workloadIdentityPools/github-pool/providers/github-provider-2
--------------------------------------------------------------------------------------------------------------------------------
List all Workload Identity Pools:
>gcloud iam workload-identity-pools list --location=global

List all Providers inside a specific Pool:
>gcloud iam workload-identity-pools providers list --workload-identity-pool=YOUR_POOL_NAME --location=global
